# Titanic Survival Prediction 🚢

My first Machine Learning project using the Titanic dataset from Kaggle.

## 📌 Project Overview

The goal of this project is to predict whether a passenger survived the Titanic disaster using Machine Learning classification models.

## 🛠️ Tools & Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 🔍 Project Workflow

1. Data Exploration and Analysis (EDA)
2. Handling Missing Values
3. Feature Engineering
4. Categorical Encoding using One-Hot Encoding
5. Feature Scaling using StandardScaler
6. Training and Evaluating Classification Models
7. Generating Predictions for Kaggle Submission

## 🤖 Models Used

- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

Decision Tree was selected based on the internal evaluation results.

## 📊 Kaggle Result

**Public Score: 0.71052**

## 📁 Files

- `Titanic.ipynb`: Complete project notebook.
- `submission.csv`: Predictions submitted to Kaggle.

[Kaggle Titanic Competition](https://www.kaggle.com/competitions/titanic)
